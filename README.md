<h1>KITCHEN-TIMER-APP</h1>

A simple and intuitive web application designed for quick kitchen timing.
Includes preset timers for commonly cooked items:

🥚 Soft-boiled egg – 4 minutes

🍞 Rye bread – 50 minutes

🎃 Pumpkin bread – 40 minutes

🍰 Vanilla cake – 25 minutes

Perfect for everyday cooking without the need to set timers manually.
